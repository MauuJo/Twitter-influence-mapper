## 1. Project Overview

This platform processes raw Twitter data through a multi-stage analytics pipeline and presents results in an interactive 7-page Streamlit dashboard. The pipeline covers:

- **Data ingestion and cleaning** from raw CSV files
- **Directed weighted graph construction** from retweet/interaction networks
- **Community detection** using the Louvain algorithm
- **Influence scoring** via PageRank, betweenness, and eigenvector centrality
- **NLP-based sentiment analysis** on tweet content using VADER
- **Topic labeling** per community using TF-IDF
- **Interactive dashboard** with network visualization

## 3. Download the Dataset

This project requires **three specific CSV files** from a public Kaggle dataset.

### Dataset URL

```
https://www.kaggle.com/datasets/deeguy/twitter-news
```

### Steps

1. Open the URL above and log in to your Kaggle account.
2. Click the **Download** button to download the full archive, or download files individually.
3. Extract the ZIP if needed.
4. Locate the three required files listed below.

### Required Files

| File Name                           | Description                                              |
| ----------------------------------- | -------------------------------------------------------- |
| `weighted_twitter_news_network.csv` | User-to-user interaction edges with weights              |
| `news_tweets.csv`                   | Raw tweet content from news discussions                  |
| `news_tweeters.csv`                 | User profile metadata (followers, verified status, etc.) |

> ⚠️ **Do NOT rename these files.** The scripts reference these exact filenames. Renaming them will cause a `FileNotFoundError`.

## 4. Folder Structure Setup

The project expects a specific folder layout. You need to create the `data/` directory and its subfolders **before** running any scripts.

### Create Required Directories

Run these commands from the **root of the project folder** (the folder containing `requirements.txt`):

**macOS / Linux:**

```bash
mkdir -p data/raw
mkdir -p data/processed
mkdir -p data/graphs
mkdir -p data/models
```

**Windows (Command Prompt):**

```cmd
mkdir data\raw
mkdir data\processed
mkdir data\graphs
mkdir data\models
```

### Place the Dataset Files

Move your three downloaded CSVs into `data/raw/`:

```
data/
  raw/
    weighted_twitter_news_network.csv   ← place here
    news_tweets.csv                     ← place here
    news_tweeters.csv                   ← place here
  processed/    (empty — files generated by scripts)
  graphs/       (empty — graph file generated by scripts)
  models/       (empty)
```

## 6. Running the Pipeline

The pipeline has **8 scripts** that must be run **in order**. Each script reads output from the previous one — do not skip steps.

> 💡 Run all commands from the **root of the project directory**.

---

### Step 1 — Load and Clean Raw Data

**Script:** `src/data_loader/load_twitter_data.py`

Reads the three raw CSVs, cleans and standardizes column names and encodings, removes bad lines, and saves processed versions.

```bash
python src/data_loader/load_twitter_data.py
```

**Output files:**

- `data/processed/cleaned_network.csv`
- `data/processed/cleaned_tweets.csv`
- `data/processed/cleaned_users.csv`

---

### Step 2 — Build the Social Graph

**Script:** `src/processing/graph_builder.py`

Constructs a directed weighted graph from the cleaned network interactions. Filters out low-degree nodes (degree < 2) and saves the graph as a binary pickle file.

```bash
python src/processing/graph_builder.py
```

**Output files:**

- `data/graphs/twitter_graph.gpickle`

---

### Step 3 — Detect Communities

**Script:** `src/analytics/community_detection.py`

Runs the Louvain community detection algorithm on the social graph to cluster users into communities. Each user is assigned a numeric community ID.

```bash
python src/analytics/community_detection.py
```

**Output files:**

- `data/processed/community_labels.csv`

---

### Step 4 — Compute Influence Metrics

**Script:** `src/analytics/influence_metrics.py`

Computes four graph-theoretic centrality measures for every user: PageRank, degree centrality, betweenness centrality, and eigenvector centrality.

```bash
python src/analytics/influence_metrics.py
```

**Output files:**

- `data/processed/influence_metrics.csv`

---

### Step 5 — Label Community Topics

**Script:** `src/analytics/topic_labeling.py`

Uses TF-IDF to extract the most representative keywords from each community's tweets. Communities with fewer than 20 tweets are skipped (too small for meaningful topic extraction).

```bash
python src/analytics/topic_labeling.py
```

**Output files:**

- `data/processed/community_topics.csv`

---

### Step 6 — Generate Insight Engine Outputs

**Script:** `src/analytics/insight_engine.py`

Merges all processed data — metrics, community labels, topic labels, and user profiles — into one master insights file. Classifies users by influence tier (Elite, Key Amplifier, Active Contributor, Peripheral) and role (Network Hub, Community Bridge, etc.), and generates an executive summary.

```bash
python src/analytics/insight_engine.py
```

**Output files:**

- `data/processed/final_social_insights.csv`
- `data/processed/executive_summary.csv`

---

### Step 7 — Run Sentiment Analysis

**Script:** `src/analytics/sentiment_analysis.py`

Uses VADER to score every tweet as Positive, Negative, or Neutral. Aggregates sentiment by community (filtering out communities with fewer than 5 tweets) and by individual influencer.

```bash
python src/analytics/sentiment_analysis.py
```

**Output files:**

- `data/processed/tweet_sentiment.csv`
- `data/processed/community_sentiment.csv`
- `data/processed/influencer_sentiment.csv`

---

### Step 8 — Generate Strategic Insights

**Script:** `src/analytics/strategic_insights.py`

Produces high-level strategic analysis: top verified and non-verified influencers, bridge accounts, largest community ecosystem, and verified vs. non-verified influence comparison.

```bash
python src/analytics/strategic_insights.py
```

**Output files:**

- `data/processed/strategic_insights.csv`

---

## 7. Quick Reference — Full Command Sequence

Copy and paste this entire block to run the pipeline from start to finish:

```bash
python src/data_loader/load_twitter_data.py

python src/analytics/community_detection.py
```

## 10. Troubleshooting

**`FileNotFoundError` on startup**

> One of the required raw CSVs is missing from `data/raw/`. Check that filenames match exactly: `weighted_twitter_news_network.csv`, `news_tweets.csv`, `news_tweeters.csv`.

**`ModuleNotFoundError`**

> A required library is not installed. Run `pip install -r requirements.txt`.

**`No module named 'community'`**

> The Louvain library is named `python-louvain` on PyPI but imported as `community`. Install it with:
>
> ```bash
> pip install python-louvain
> ```

**`MemoryError` during graph building or centrality computation**

> These steps are RAM-intensive and may require 4–8 GB of available memory. Close other applications and retry.

**Streamlit shows `None` in community label / keyword columns**

> Not all pipeline steps completed. Ensure all 8 scripts ran without errors and all 12 files exist in `data/processed/` before launching the app.

**`LookupError: vader_lexicon not found`**

> ```bash
> python -c "import nltk; nltk.download('vader_lexicon')"
> ```
